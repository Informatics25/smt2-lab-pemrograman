# 📘 Modul 2: Manajemen Memori & Struktur Linear

## 📝 Ikhtisar Modul
Modul ini beralih dari sintaks dasar ke "cara C++" dalam menangani data[cite: 2]. Kita akan mengeksplorasi bagaimana *pointer* menjembatani kode dengan perangkat keras, bagaimana memori dinamis di *Heap* dialokasikan dan dibebaskan, bagaimana *array* dan *vector* mengorganisasi data secara linear, serta cara memanipulasi *string* dengan aman[cite: 2].

## 🎯 Capaian Pembelajaran Modul
Setelah menyelesaikan Modul 2, mahasiswa akan mampu:
* **CP1:** Menjelaskan hubungan antara variabel, alamat memori, dan *pointer*[cite: 2].
* **CP2:** Menggunakan operator *address-of* (`&`) dan *dereference* (`*`) dengan benar[cite: 2].
* **CP3:** Membedakan alokasi *Stack* dan *Heap* serta menggunakan `new` dan `delete` dengan aman[cite: 2].
* **CP4:** Mengimplementasikan dan memanipulasi *array* statis dan `std::vector` dinamis[cite: 2].
* **CP5:** Melakukan operasi *string* umum menggunakan C-style *string* dan `std::string`[cite: 2].
* **CP6:** Melakukan *debugging* pada kesalahan memori, termasuk *null pointer*, *dangling pointer*, dan kebocoran memori[cite: 2].
